## 2. 先给结论

当前系统已经形成了一个较完整的后台应用安全基础：账号唯一约束、RBAC、最小权限、登录失败锁定、服务端会话撤销、TOTP MFA 能力、可选的邮箱验证码 MFA、参数化查询、CSP、安全审计链式哈希、加密备份和个人资料导出/注销接口均已存在。

但当前不能认定为“已经满足应用系统等级保护要求”。主要原因是：

1. 双因素认证的应用能力已完成，支持密码 + TOTP 和可选的密码 + 邮箱验证码；邮箱 MFA 默认关闭，由系统管理员配置并测试 SMTP，再由安全管理员启用策略。生产仍需完成目标账号启用和证据留存。
2. 应用层存储加密已经补齐：用户邮箱、显示名、备注、头像、登录 IP，以及审计账号/IP/前后值等敏感字段在 SQLite 中使用 AES-256-GCM 加密；生产密钥、KMS/HSM、TDE、展示脱敏和现场设施仍需单独落实。
3. 剩余信息清除已经补齐应用层会话记录删除、SQLite 安全擦除、WAL/表空间回收、密码表单清空和审计输出脱敏；JavaScript 运行时内存覆写、既有备份副本/快照同步删除和基础设施缓存仍不能仅靠当前代码证明。
4. TLS、VPN、WAF、IDS/IPS、HIDS/EDR、集中日志、WORM、KMS/TDE、异地机房、数据库复制、负载均衡和应急响应都没有在当前仓库中形成可核验的生产证据。
5. 个人信息告知确认在后端是可选字段，且写入用户时无论是否确认都会写入当前时间，不能据此证明真实同意；个人信息自动清理、访问审批和第三方共享授权也未形成闭环。
6. 合规中心的“18 项通过”是应用层运行证据的计算结果。E2E 测试通过时使用临时目录模拟异地备份，主动设置 `HA_ENABLED=true`，并手工登记漏洞扫描结果，不能替代真实异地站点、HA 集群或扫描平台的证据。

按附录 18 项的保守分类：已完成（应用层）9 项，未完成 2 项（第 17 项为部分实现），当前条件无法确认/完成 7 项；部分实现不计入“已完成”。双因素认证、应用层安全审计、应用层输入验证和应用层存储加密控制已经完成，但生产启用范围、密钥设施、集中日志和现场证据仍需确认。

当前工作区未发现实际 `.env`、运行数据库或生产备份目录，只有 `.env.example` 配置模板和本次构建生成的 `.output`；因此当前实际账号 MFA 状态、生产 TLS、异地备份和 HA 状态不能从工作区直接确认。

## 6. 需要优先补齐的事项

### P0：进入正式测评/生产前必须处理

1. 修正 TLS 信任边界：只接受受控反向代理写入的 `X-Forwarded-Proto`，配置可信代理、证书、TLS 1.2/1.3、弱套件禁用，关闭 API 明文直连端口，并落实 VPN/堡垒机。
2. 启用并留证 MFA：由安全管理员启用管理员强制 MFA；可选择认证器 MFA，或在系统管理员完成 SMTP 配置/测试后启用邮箱 MFA，并完成所有目标账号的邮箱维护、解绑/恢复流程和审计；同时明确普通用户是否纳入测评范围。
3. 盘点历史账号口令：对策略改动前创建的账号执行强制改密或风险复核，保留结果，并确认生产策略不可被关闭；继续补充 IP/设备级登录限流。
4. 修正个人信息告知：后端必须拒绝缺少 `privacyNoticeAccepted=true` 的创建请求，保存告知版本/内容摘要和同意证据，不能把默认时间当作同意。
5. 应用层安全审计已启用；仍需建设独立日志服务器/SIEM + WORM/对象锁，接收认证、授权、个人信息访问、业务读写和安全设备事件，并落实 12 个月留存、备份、完整性校验和告警。
6. 解决存储保密和密钥管理：生产禁止 JWT/备份开发默认密钥兜底，接入 KMS/HSM/TDE 或经评估的字段/文件加密，增加邮箱等个人信息脱敏。

### P1：需要真实基础设施或管理制度

1. 部署 WAF、IDS/IPS、HIDS/EDR、防病毒网关和告警平台，形成规则、日志、告警和应急演练证据。
2. 建立漏洞管理制度和 CI/CD 扫描门禁，至少季度扫描，关联 CVE/CNNVD，设定高危 72 小时 SLA、补丁测试、风险接受和回滚记录。
3. 建立本地全量/增量、异地加密复制、自动保留清理和季度恢复演练，提供异地距离、链路、RTO/RPO 证明。
4. 若目标等级要求高可用，迁移单机 SQLite 方案或补充经过验证的高可用存储，部署多实例、负载均衡、故障切换和共享密钥/会话。
5. 建立数据资产分级、主体安全级别、MAC/数据标签、个人信息访问审批和第三方共享授权制度，并将其接入每个业务资源。
6. 应用层已补充 SQLite/WAL 删除、会话清理、表单清空和审计输出脱敏；仍需把安全删除扩展到备份/上传文件/快照/复制副本，并建立个人信息自动留存清理方案。
